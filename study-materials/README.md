# Study Materials

This folder documents the two carts used in the MARC study: what each cart held, where each item was, and which items participants retrieved in each condition.

The inventory tables are generated from the files the software loads (`backend/inventory-layperson.json` and `backend/inventory-rn.json`), so they match exactly what the interface shows. Each item's drawer and compartment is also the location announced by the speech cue ("Located in drawer {drawer}, compartment {compartment}"). Item photos are in `backend/public/images-layperson/` and `backend/public/images-rn/`.

## Layperson cart

General-purpose office, lab, and workshop supplies, used with the 11 layperson participants.

### Target items by condition

Participants retrieved 5 items per condition. Each condition used a largely distinct set of items so that participants could not rely on memory from earlier conditions.

| Condition | Target items |
|---|---|
| C1 Manual search | Spanner, Mouse, Glue Gun, Screw, Edge Guard |
| C2 Web interface only | Sharpie, Game Controller, Goggles, Battery, SD Card |
| C3 Web interface + LEDs | Craft Knife, White Glue, Spray, Scissors, Goggles |
| C4 LEDs only | Stapler, Pliers, Extension Box, Gloves, Pencil |
| C5 Speech only | HDMI Cable, Marker, Super Glue, Wire, Camera |
| C6 Web interface + speech | Tape Measure, Screwdriver, Scotch Tape, Spanner, Mouse |

Across the six conditions, 30 targets were retrieved from 27 distinct items, because spanner, mouse, and goggles each appear in two conditions.

Participants practiced with the **Wire** before the main task.

## Registered nurse (RN) cart

Authentic crash-cart supplies (disposables, devices, medications, and fluids), used with the 5 registered nurses.

### Target items by condition

Participants retrieved 3 items per condition. Each condition used a different set of items, so no item was a target more than once.

| Condition | Target items |
|---|---|
| C1 Manual search | PI Surgical Gloves, 5% Dextrose Injection USP (500 mL), Magnesium Sulfate (500 mg/ml, 2ml Vial) |
| C2 Web interface only | 3-way Stopcock, Atropine Sulfate (1mg/10 ml DU), 60 mL Syringe |
| C3 Web interface + LEDs | Push Button Blood Collection Set, Furosemide (10 mg/ml, 4ml vial), Shielded IV Catheter |
| C4 LEDs only | Transparent Film Dressing, N95 Respirator Mask, 0.9% Sodium Chloride Injection USP (500 mL) |

In total, 18 distinct items were used as targets.

## Distractors

In both carts, the target items were placed among additional non-target supplies, so participants searched a fully stocked cart rather than a sparse one.
