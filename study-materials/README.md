# Study Materials

This folder documents the two cart configurations used in the CueBot study. The tables below are generated from the inventory files the software loads (`backend/inventory-layperson.json` and `backend/inventory-rn.json`), so they match exactly what the interface shows.

Each row gives the item's drawer and compartment, which is also the location announced by the speech cue ("Located in drawer {drawer}, compartment {compartment}"). Item reference photos are in `backend/public/images-layperson/` and `backend/public/images-rn/`.

## Task cards

At the start of each condition, participants received a task card listing the names and reference photos of the items to retrieve. Each condition used a largely distinct set of target items so that participants could not rely on memory from earlier conditions.
